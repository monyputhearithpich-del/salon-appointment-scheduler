# Salon Appointment Scheduler

A command-line salon appointment scheduling application built with Bash and PostgreSQL as part of the freeCodeCamp Relational Database curriculum.

## Features

* Display available salon services.
* Collect customer information.
* Register new customers.
* Schedule appointments for selected services.
* Store and retrieve customer and appointment information using PostgreSQL.

## Technologies Used

* Bash
* PostgreSQL
* SQL
* Git and GitHub

## Project Files

* `salon.sh` — Bash script that manages the appointment scheduling workflow.
* `salon.sql` — SQL script defining the database structure.
* `examples.txt` — Example project data or commands.

## How to Run

1. Install PostgreSQL and Bash.
2. Start the PostgreSQL service.
3. Create and configure the required database.
4. Run the SQL setup script.
5. Execute the application:

   ```bash
   ./salon.sh
   ```
